# AI Agents Academy — 11-768 (CMU)

Học liệu tự học bám theo bài giảng **11-768: AI Agents** (Carnegie Mellon University, Fall 2026).
Song ngữ Việt/Anh · HTML tĩnh · chạy offline.

**🌐 Web:** https://nguyentiendat96.github.io/ai-learning-web/

## Nội dung

- `lessons/` — 9 bài giảng (tự chứa, có quiz + thực hành tự kiểm + thực hành code)
- `exams/` — 9 exam theo bài (13 câu tương tác + 3 tình huống + bài tập code) và 3 đề thi thử tính giờ
- `reference/` — bản đồ khóa học + lộ trình chứng chỉ AI/agentic
- `assets/` — CSS/JS dùng chung (quiz engine, chuyển ngữ VI/EN)

## Ghi chú

- Slide gốc **không kèm** trong repo — tải tại [cmu-agents.com](https://www.cmu-agents.com).
- Nội dung biên soạn cho mục đích học tập, mỗi bài có trích dẫn nguồn theo trang slide.
- Trang chạy hoàn toàn tĩnh (không build step) — mở `index.html` là dùng được.
