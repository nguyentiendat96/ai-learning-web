# Harness Engineering — tài liệu bổ sung

Bộ học liệu bổ trợ (tiếng Việt, chạy offline) về **harness engineering** — tầng hệ thống quanh model: vòng lặp agent, thiết kế tool, context, sandbox & an toàn, verification, chạy dài hạn.
Dựng từ handbook *"Understanding Harness Engineering"* (@techNmak, series Understanding AI) — liên quan trực tiếp Bài 02–07 của khóa 11-768 và track Claude.

## Files

| File | Nội dung |
|---|---|
| `harness-engineering-course.html` | Khóa học tương tác 43 mục: bài học có theo dõi tiến độ, quiz 40 câu, flashcards, bảng tra, nút xuất PDF |
| `design.html` | 18 sơ đồ flow của toàn bộ handbook (mở bằng trình duyệt) |
| `design.md` | Nguồn Markdown các sơ đồ (Mermaid) — xem trên GitHub/VS Code/Obsidian |
| `mermaid.min.js` | Thư viện vẽ sơ đồ, giúp `design.html` chạy offline (3.5 MB) |

## Ghi chú

- Mở nhanh: `harness-engineering-course.html` → nút **🗺 Sơ đồ** (góc phải trên) mở `design.html`.
- **Chưa** gắn vào `web/index.html`; **chưa** song ngữ VI/EN (khác chuẩn lessons 01–09).
- Handbook gốc (PDF) để ngoài repo, tại `C:\Projects\documents\` — cùng chính sách với slide CMU.
