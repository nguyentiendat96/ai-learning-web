def find_target(screen, label):
    for r, row in enumerate(screen):
        for c, cell in enumerate(row):
            if cell == label:
                return (r, c)
    return None

Điểm cần chú ý: quét theo thứ tự hàng rồi cột để "ô đầu tiên" có nghĩa xác định, và trả None khi hết lưới.     return abs(start[0] - goal[0]) + abs(start[1] - goal[1])

Đây chính là khoảng cách Manhattan: chỉ đi ngang/dọc nên số bước tối thiểu = chênh lệch hàng + chênh lệch cột. Ghép với D1, bạn có pipeline thu nhỏ của một bước CUA: tìm toạ độ mục tiêu, rồi tính đường tới đó. Trên màn hình thật, agent click thẳng tới toạ độ — cái khó không phải đường đi mà là tìm đúng toạ độ (grounding).This is exactly Manhattan distance: since movement is only horizontal/vertical, the minimum number of steps = row difference + column difference. Combined with D1, you have a miniature pipeline of one CUA step: find the target coordinates, then compute the path to them. On a real screen, the agent clicks straight to the coordinates — the hard part is not the path but finding the right coordinates (grounding).
