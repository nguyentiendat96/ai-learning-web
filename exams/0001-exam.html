Phần A — Trắc nghiệm (10 câu)Part A — Multiple choice (10 questions)

A1. Theo định nghĩa Russell & Norvig, agent là gì?A1. According to the Russell & Norvig definition, what is an agent?

Định nghĩa không nói gì về độ thông minh — chỉ nói về cặp "nhận biết → hành động".The definition says nothing about intelligence — only about the perceive → act pair.

A2. Trong một coding agent, đâu là "sensors" (bộ cảm biến)?A2. In a coding agent, what are the "sensors"?

Sensors = kênh nhận thông tin vào. Với agent phần mềm: đọc file, nhận message, nhận kết quả tool.Sensors are the input channels. For a software agent: reading files, receiving messages, receiving tool results.

A3. "Kết quả pytest trả về: 1 passed" — mô tả nào đúng nhất?A3. "pytest returned: 1 passed" — which description fits best?

Nó đến từ môi trường (observation), và là tín hiệu cho biết task đã xong (reward).It comes from the environment (observation), and it signals that the task is done (reward).

A4. Điều gì khiến một hệ thống là agent chứ không chỉ là chatbot?A4. What makes a system an agent rather than just a chatbot?

Bản chất nằm ở vòng lặp tác động lên môi trường — không phải kích thước model.The essence is the loop acting on an environment — not the size of the model.

A5. Theo lecture, đâu là ví dụ của reward trong hệ agent phần mềm?A5. According to the lecture, which is an example of reward for a software agent?

Reward = tín hiệu đánh giá kết quả. Token/thời gian là chi phí; số lần gọi tool là hành vi.Reward = a signal judging the outcome. Tokens/time are cost; tool-call counts are behaviour.

A6. Điều nào sau đây KHÔNG phải là action của agent?A6. Which of the following is NOT an action of the agent?

Action là thứ agent chủ động làm lên môi trường. Suy nghĩ nội bộ không tác động ra ngoài.An action is something the agent does to the environment. Internal thinking does not affect the outside world.

A7. Điều hòa nhiệt độ có phải agent theo định nghĩa của lecture không?A7. Is a thermostat an agent under the lecture's definition?

Định nghĩa rộng hơn bạn tưởng: điều hòa có sensors (cảm biến nhiệt) + actuators (bật/tắt máy nén).The definition is broader than you think: a thermostat has sensors (temperature) and actuators (the compressor switch).

A8. "Environment" của một coding agent đang sửa bug là gì?A8. What is the "environment" of a coding agent fixing a bug?

Environment = "thế giới" mà agent tác động vào — ở đây là repository (và cả cuộc hội thoại).The environment is the world the agent acts on — here, the repository (and the conversation).

A9. Đâu là mô tả đúng về observation?A9. Which description of an observation is correct?

Observation phải đến từ môi trường: kết quả lệnh, nội dung file, kết quả tool.An observation must come from the environment: command output, file contents, tool results.

A10. Vì sao nói "agent là một cách nhìn" (a way of viewing)?A10. Why do we say an agent is a "way of viewing"?

Định nghĩa dùng chữ "can be viewed as" — bạn nhìn hệ thống qua cặp nhận biết → hành động để thấy environment/observations/actions/reward của nó.The definition says "can be viewed as" — you view a system through the perceive → act frame to see its environment/observations/actions/reward.

C2. Máy giặt thông minh: viết ra 4 thành phần (environment / observations / actions / reward).A smart washing machine: write out the four components (environment / observations / actions / reward).

Xem đáp án gợi ýSee suggested answer

  • Observations: cảm biến khối lượng quần, trạng thái cửa, mức nước…Observations: clothes-weight sensor, door state, water level…

C3. Tìm lỗi: một bạn nói "Observation là suy nghĩ của model". Sai ở đâu? Sửa lại cho đúng.Find the mistake: someone says "An observation is the model's thoughts." What is wrong? Fix it.

Xem đáp ánSee answer

Sai: observation là thứ môi trường trả về (kết quả tool, nội dung file, tin nhắn) — không phải suy nghĩ của model. Suy nghĩ nội bộ là phần model tự sinh, không đến từ môi trường. Cách sửa: "Observation là thông tin môi trường trả về cho agent; còn suy nghĩ của model không phải observation."Wrong: an observation is what the environment returns (tool results, file contents, messages) — not the model's thoughts. Internal thinking is generated by the model; it does not come from the environment. Fixed version: "An observation is information the environment returns to the agent; the model's thoughts are not observations."

Xem lời giảiSee solution 
def summarize(trace):
    actions = sum(1 for kind, _ in trace if kind == "ACT")
    observations = sum(1 for kind, _ in trace if kind == "OBS")
    obs_steps = [text for kind, text in trace if kind == "OBS"]
    return {
        "actions": actions,
        "observations": observations,
        "reward_step": obs_steps[-1] if obs_steps else None,
    }
