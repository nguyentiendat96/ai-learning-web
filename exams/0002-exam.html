Checklist tự kiểmSelf-check checklist

Câu trả lời tốt cần đủ 3 ý: (1) tool call chỉ là một chuỗi token model viết ra — định nghĩa tool được chat template nhét vào prompt như text; (2) harness đọc chuỗi đó, validate và thực thi thật; (3) kết quả được đưa trở lại ngữ cảnh như một observation mới, để model quyết định bước tiếp.A good answer needs all three points: (1) a tool call is just a string of tokens the model writes — the tool definition is stuffed into the prompt as text by the chat template; (2) the harness reads that string, validates it, and actually executes it; (3) the result is fed back into the context as a new observation, so the model can decide the next step.

C3. Tìm lỗi: "Tool call là model tự chạy chương trình." — Sai ở đâu? Sửa lại cho đúng.Find the mistake: "A tool call is the model running the program itself." — What is wrong? Fix it.

Xem đáp ánSee answer

Sai: model không chạy chương trình — nó chỉ đề nghị (sinh chuỗi token). Phần mềm bên ngoài (harness) mới là bên quyết định và thực thi. The external software (the harness) is the one that decides and executes. Fixed: "A tool call is the model proposing to call a tool; the harness checks it, executes it, and returns the result."

def parse_tool_call(text):
    m = re.search(r"<tool_call>(.*?)</tool_call>", text, re.DOTALL)
    if not m:
        return None
    return json.loads(m.group(1))

def run_agent(model_outputs, tools):
    messages = []
    for output in model_outputs:
        messages.append({"role": "assistant", "tool_call": output})
        if output["name"] == "finish":
            messages.append({"role": "assistant", "content": output["arguments"]["text"]})
            break
        result = tools[output["name"]](**output["arguments"])
        messages.append({"role": "tool", "content": result})
    return messages
