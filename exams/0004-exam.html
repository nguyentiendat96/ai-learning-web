Nguyên nhân 1 — drift qua nhiều lần nén: bản nén mới viết từ bản nén cũ + phần mới; ràng buộc bị diễn giải dần ("không đổi schema API" → "hạn chế đổi API" → biến mất).Cause 1 — drift across repeated compaction: each new summary is written from the old summary + the new part; the constraint gets paraphrased away ("don't change the API schema" → "avoid changing the API" → gone).

Nguyên nhân 2 — hướng dẫn cũ bị loãng: dù chưa nén, ràng buộc nằm ở đầu session có thể bị hàng nghìn token phía sau làm nhạt; thông tin ở giữa ngữ cảnh cũng dễ bị bỏ sót (lost in the middle).Cause 2 — old instructions diluted: even without compaction, a constraint near the start of the session can be washed out by thousands of tokens after it; information in the middle of the context is also easily missed (lost in the middle).

def compact(messages, max_chars):
    systems = [m for m in messages if m["role"] == "system"]
    convo = [m for m in messages if m["role"] != "system"]
    budget = max_chars - sum(len(m["content"]) for m in systems)

    for d in range(len(convo) + 1):
        kept = convo[d:]
        used = sum(len(m["content"]) for m in kept)
        if d:
            summary = {"role": "summary", "content": f"[compacted {d} messages]"}
            used += len(summary["content"])
        else:
            summary = None
        if used <= budget:
            return systems + ([summary] if summary else []) + kept

    return systems + [{"role": "summary", "content": f"[compacted {len(convo)} messages]"}]

def usage(prefix_k, per_step_k, n):

    total = n * prefix_k + per_step_k * n * (n - 1) // 2
